# PCL 联网下载解锁  v1.0

一个**单文件 exe**（389 KB，自带 Mono.Cecil，无需安装任何运行库以外的依赖）。
放到 PCL 所在文件夹里双击，就会给同目录的 PCL 主程序打上 4 处定点补丁，**解除作者硬编码的联网/下载限制**。

| 项目 | 值 |
|---|---|
| 文件 | `PCL联网下载解锁.exe` |
| 大小 | 389,632 字节 |
| SHA-256 | `2AFF62CAFA1DD003A02EA7EB126FE66879920168C81FD5A909DAC5C979051B7E` |
| 运行环境 | .NET Framework 4.8（PCL 本身也要求 4.8，所以任何能跑 PCL 的机器都能跑） |
| 修改方式 | IL 定点补丁（Mono.Cecil），不重新编译、不动 XAML/BAML 资源 |

---

## 用法

1. 完全退出 PCL（否则文件被占用会失败）
2. 把 `PCL联网下载解锁.exe` 放进 PCL 所在文件夹（和 `Plain Craft Launcher 2.exe` 同级）
3. 双击运行
4. 看到「完成」后重新打开 PCL 即可

也可以把 PCL 的 exe 直接拖到本工具图标上，或用命令行：

```cmd
PCL联网下载解锁.exe "D:\Games\PCL\Plain Craft Launcher 2.exe"
```

自动备份：首次运行会生成 `Plain Craft Launcher 2.exe.pclunlock.bak`，想回滚就把 `.bak` 改回原文件名覆盖即可。

## 它到底改了什么

| # | 位置 | 原始行为（作者限制） | 补丁后 |
|---|---|---|---|
| 1 | `Settings.Get` 里的 `ForcedSettings` | 硬编码把 `UiHiddenPageLink` / `UiHiddenSetupLink` 强制设为 `true`，用户怎么设置都关不掉/开不了 | 键名改写为 `…Link#unlocked`，强制项永不命中 → 联机页、联机设置页恢复按用户设置显示 |
| 2 | `ModSecret.HasUpdatePermission` | 快照版里要求「赞助等级 ≥ 12」或土豆码含 `Update` 特征才能更新/下载启动器 | 恒为 `true`，不再需要赞助码 |
| 3 | `ModSecret.ServerSub` 公告循环 | 服务端下发的 `isUpdate` 公告（就是那条「**悲报：为遵守相关法律法规，PCL 不再提供 MC 下载功能**」）会弹模态窗拦截 | 注入 `PCLFix.Hooks.NeutralizeIfUpdate`，跳过所有 `isUpdate` 公告 |
| 4 | `PageSetupUI.HiddenRefresh` | `BtnTitleSelect2.Visibility = Visibility.Collapsed` —— 导航栏「联机」按钮被**无条件**隐藏 | 改为 `Visible`，导航栏恢复「启动 / 下载 / 联机 / 设置 / 更多」 |

> 第 3 条是"联网下载"最直观的限制：那条弹窗就是作者下发的、告诉你不再提供下载的通知。补丁后它不再出现，下载页照常工作（实测版本列表 425 ms 正常拉取）。

## 兼容性（已实测）

| 目标 | 结果 |
|---|---|
| **快照版 2.14.0.0 (412)** | 4 项全部 `[OK]`；打完启动正常、无 E/W 日志、导航栏出现「联机」 |
| **正式版 2.13.1.1** | 3 项 `[OK]`，第 2 项 `[SKIP]`（该版本 `HasUpdatePermission` 本来就是 `true`） |
| 其它 2.x 版本 | 按特征匹配，缺哪项就 `[SKIP]` 哪项，不会把程序打坏；程序集名不是 `Plain Craft Launcher*` 会直接拒绝 |

工具是**幂等**的：已经打过补丁的程序再跑一次会全部 `[SKIP]`，不会重复注入。
它也认得 `PCL Fix.exe`（我上次做的改名版）——如果那个版本已经有 `PCLFix.Hooks` 类型，会直接复用。

## 已知限制（说清楚，避免误解）

1. **更新下载无法凭空恢复**：如果目标版本里 `ModSecret.UpdateStart` 已经被清空（破解版就是这样），本工具不会凭空写回一个下载器，所以「检查更新」仍然不可用。工具只解除**门槛**（赞助码/权限），不重建被删掉的代码。
2. **联机功能仍受服务端开关限制**：`ServerConfig.Link.DisableReason` 目前是「联机功能已暂时关闭」，所以点进联机页会看到这句提示，这是服务端下发的，不是本地能改的。
3. **PCL 的下载页本身没有被代码封锁**：实测版本列表能正常拉取。如果你那边下载页打不开，先确认是不是被自己的设置隐藏了（设置 → 个性化 → 隐藏功能 → 下载页），本工具只解除了作者硬编码的部分，不会覆盖你自己的偏好。
4. 只支持 .NET 程序集（PCL 2.x 全部是），不支持 PCL 1.x（那是 C++ 原生程序）。

## 源码

`源码/` 目录是完整可编译的工程（.NET Framework 4.8 + Mono.Cecil + Costura.Fody 单文件打包）：

```powershell
dotnet build .\源码 -c Release
# 产物：源码\bin\Release\PCL联网下载解锁.exe
```

补丁点都在 `Program.cs` 的 `PatchForcedHiddenPages` / `PatchHasUpdatePermission` / `PatchUpdateNotice` / `PatchLinkPage` 四个方法里，想加/减改动点直接改这里。

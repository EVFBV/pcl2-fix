## 4. 启动流程（三阶段，均有计时日志）

### 阶段一 — `Application.Application_Startup`

1. `MeloongCore.Main.Init("PCL")` + `Main.Init()`（框架初始化）
2. 非 `--update / --gpu / --memory` 时：**单实例互斥体 `PCL_SingletonMutex`**（`WaitingMutex`，已存在则把已有窗口置前并退出）
3. 日志器初始化：`PclLogger { logFolder = Paths.BaseThenName }`，`MinLevel = ModeDebug ? Debug : Info`
4. 主线程优先级提到 `Highest`
5. **.NET Framework 4.8 检测**（注册表 `NDP\v4\Full\Release < 528040` 则弹环境警告）
6. `FormattedText` 探测字体环境（捕获 `UriFormatException` 时改写 `windir` 环境变量后重试）
7. **命令行分发**
   - `--update <pid> <old> <new> <restart>` → `ModSecret.UpdateReplace(...)` → `Environment.Exit(5)`
   - `--gpu <exe>` → `ModMain.SetGPUPreference(...)`
   - `--memory` → `PageOtherTest.MemoryOptimizeInternal(...)`，以可用物理内存增量作为退出码
8. 创建 `PCL\Pictures\`、`PCL\Musics\` 并做**写权限探测**（失败弹「运行环境错误」并 `Exit(4)`）
9. 缓存目录 `PathTemp` 校验，失败可回退到 `%TEMP%\PCL\` 并改写设置
10. `ServicePointManager` 调优：`Expect100Continue=false`、`DefaultConnectionLimit=10000`、`UseNagleAlgorithm=false`、`EnableDnsRoundRobin=true`、`ReusePort=true`；<Win8 追加 TLS 协议
11. `UiLauncherLogo` 开启时显示 `SplashScreen("Images\icon.ico")`
12. 记录版本、识别码、路径、编码、管理员权限
13. 拒绝「从压缩包直接运行」（路径含 `Temp`）与 32 位系统
14. 日志 `第一阶段加载用时：N ms`

### 阶段二 — `FormMain` 构造 + `FormMain_Loaded`（前段）

句柄获取 → 背景/标题栏刷新 → `PageSetupUI.HiddenRefresh()` + `BackgroundRefresh()` → 音乐恢复 →
侧栏按钮 `ShowCheck` 委托注册 → `MyResizer` 注册 8 个缩放手柄 → 主题刷新 `ModSecret.ThemeRefreshMain()` →
窗口尺寸恢复 → 关闭 Splash → 居中 → `HwndSource.AddHook(WndProc)`（自定义窗口消息）→
**入场动画**（透明度 + 位移 + 旋转，`ModAnimation.AniStart`）→ `ModMain.TimerMainStart()` → 日志 `第二阶段加载用时`

### 阶段三 — 后台初始化线程（`ThreadPriority.Lowest`）

1. 用户协议版本检查（`SystemEulaVersion < 2` 弹窗，拒绝则退出）
2. `ModJava.JavaInit()` — Java 探测
3. `ModDownload.DlClientListMojangLoader.Start(1)` — 拉取 Minecraft 版本清单
4. `RunCountSub()` — 统计运行次数（`SystemCount`）
5. **`ModSecret.ServerLoader.Start()`** — 拉取服务器公告与配置（破解版仍然保留）
6. `ModMain.TryClearTaskTemp` — 清理临时任务目录
7. 删除 `PCL\Plain Craft Launcher 2.exe`（上一次自更新留下的副本）
8. `ModMain.Telemetry("启动")` — 匿名统计上报
9. 日志 `第三阶段加载用时：N ms`

## 5. 核心框架

### 5.1 加载器框架 `ModLoader`

VB 里叫「加载器」，本质是一个**可组合的异步任务树 + 进度聚合 + 任务栏 UI**。

```
LoaderBase (abstract, ILoadingTrigger)
├─ LoaderTask<TIn,TOut>      单步任务：Start(Input) → 返回 Output
├─ LoaderWorker              无输入输出
├─ LoaderCombo<T>            组合加载器：持有 List<LoaderBase>，按 ProgressWeight 聚合进度
└─ (ModNet) LoaderDownload   下载专用（多 URL / 多线程 / 断点 / 校验）
```

- 状态机：`LoadState = Waiting | Loading | Finished | Failed | Canceled`
- 事件：`OnStateChangedThread` / `OnStateChangedUi` / `PreviewFinish` / `LoadingStateChanged` / `ProgressChanged`
- 关键成员：`ProgressWeight`、`Block`、`Show`、`ReloadTimeout`、`WaitForExit()`、`WaitForExitTime()`
- 任务栏：`LoaderTaskbarAdd<T>()` + `LoaderTaskbarProgressRefresh()` 把加载器树投影到标题栏进度条
- 文件夹加载器：`LoaderFolderRun(Loader, FolderPath, LoaderFolderRunType, MaxDepth)` 按目录最后写入时间做增量刷新
- UI 绑定：`MyPageRight.PageLoaderInit(LoaderUi, PanLoader, PanContent, PanAlways, RealLoader, ...)` 把加载器状态映射到「加载中/内容/常驻」三个面板

### 5.2 页面与导航框架

- 页面基类：`MyPageRight`（右侧内容页）与 `MyPageLeft`（左侧列表页）
- 生命周期：`PageOnEnter` / `PageOnExit` / `PageOnForceExit` / `PageOnContentExit`，`PageState` 枚举，`PageUuid`
- 转场动画：`TriggerEnterAnimation` / `TriggerExitAnimation`，可屏蔽 `DisabledPageAnimControls`
- 页面栈：`FormMain.PageChange(PageStackData Stack, PageSubType SubType)` + `PageChangeActual` + `PageChangeAnim`，`PageBack()` 出栈，`PageNameRefresh()` 更新标题
- 页面族（`PageSubType`）：Download（Install/Mod/Pack/DataPack/ResourcePack/Shader）、Setup（Launch/Link/UI/System）、
  Link、Other（Help/About/Test）、Instance（Overall/Setup/Modify/Mod/ModDisabled/Export）

### 5.3 设置系统 `Settings`

- 192 条 `new Setting(key, default, source, encrypted, onChanged)` 注册
- 三种存储源 `Sources = Normal | Registry | Instance`
  - `Normal`：`PCL\Setup.ini`
  - `Registry`：`HKEY_CURRENT_USER\Software\PCL`（`ModSecret.RegFolder`），用于跨目录共享
  - `Instance`：实例目录内的独立配置
- `Encrypted: true` 的项（如 `UiLauncherThemeHide2`、`Potatoes`）经 `MeloongCore` 加密后落盘
- 带 `OnChanged` 回调的项会即时生效（如 `UiLauncherTheme` → `ModSecret.ThemeRefresh`）
- 读取走内存缓存 `ConcurrentDictionary`，写入走 `SettingService`（去抖 + 脏标记）

### 5.4 事件总线 `CustomEvent`

25 个事件类型（`CustomEvent.EventType`）：`打开网页 / 打开文件 / 打开帮助 / 执行命令 / 启动游戏 / 复制文本 /
刷新主页 / 刷新页面 / 刷新帮助 / 今日人品 / 内存优化 / 清理垃圾 / 弹出窗口 / 弹出提示 / 切换页面 /
导入整合包 / 安装整合包 / 下载文件 / 修改设置 / 写入设置 / 修改变量 / 写入变量 / 加入房间 / 检查更新`。
用于「自定义主页 / 自定义帮助 / 自定义事件 JSON」等外部扩展点，`CustomEventService` 负责注册与派发。

### 5.5 动画 `ModAnimation`

自研时间轴引擎：`AniStart(List<AniData>, Name)`、`AniControlEnabled`（全局开关，用于批量布局时抑制动画）、
`AaOpacity / AaDouble / AaCode / AaColor / AaWidth / AaScale` 等原语，缓动 `AniEaseOutBack` 等，`AniSpeed` 全局倍速。
所有页面转场、提示气泡、列表项进入都是这套引擎驱动的。

### 5.6 自绘控件库（`Controls\`，25 个）

`MyButton / MyTextButton / MyIconButton / MyIconTextButton / MyExtraButton / MyExtraTextButton /
MyCheckBox / MyRadioButton / MyRadioBox / MyComboBox(Item) / MyTextBox / MySearchBox / MySlider /
MyScrollBar / MyScrollViewer / MyListItem / MyCard / MyHint / MyLoading / MyImage / MyDropShadow /
MyResizer / MyMenuItem / MyVirtualizingElement / MyMsgText|Input|Select / MySkin / MyLocalModItem / MyResourceItem`
外加行为 `ClipboardInterceptor`（拦截 DataGrid 复制）、`LazyLoadBehavior`（滚动懒加载）。

### 5.7 校验框架

`Validate` 抽象基类 + 15 个实现：`ValidateNullOrEmpty / ValidateNullOrWhiteSpace / ValidateLength /
ValidateRegex / ValidateInteger / ValidateFileName / ValidateFolderName / ValidateFolderPath / ValidateHttp /
ValidateSame / ValidateExcept / ValidateExceptSame / ValidateNullable / ValidateFunc`，
配合 `MyTextBox` 的 `ValidateRules` 集合做即时校验。

## 6. 业务子系统

### 6.1 网络层 `ModNet`

- `NetManagerClass`：静态门面（`NetRequestByClient` / `NetRequestByClientRetry` / `NetRequestByClientMultiple` /
  `NetRequestByLoader` / `NetDownloadByClient` / `NetDownloadByLoader`）
- `NetThread`：单条下载的分片线程，`NetTaskThreadLimit = ToolDownloadThread + 1`
- `NetFile`：{ URL 列表, 本地路径, 大小, 哈希, 校验器 }，支持多源回退
- `LoaderDownload`：把 `NetFile` 列表包装成加载器（进度、限速、失败重试、镜像切换）
- 镜像改写：`ModDownload` 内置 Modrinth / CurseForge / ForgeCDN → `mod.mcimirror.top` 等镜像替换表
- 缓存：`CacheCow.Client.FileStore` 做元数据磁盘缓存
- 全部请求经 `ModSecret.SecretHeadersSign` 注入 UA / Referer / CurseForge `x-api-key`，
  经 `ModSecret.SecretCdnSign` 为 `{CDN}` 结尾的 URL 追加 **MD5 签名**

### 6.2 下载与资源

- `ResourceSearcher`：统一搜索接口（CurseForge API v1、Modrinth API v2、MCIMirror 镜像），
  中文搜索走权重相似度（`ModBase.Search` / `SearchSimilarityWeighted`）
- `ResourceProject` / `ResourceVersion`：项目与文件版本模型，含 release type、依赖、更新记录
- `ModDownloadLib`：安装编排器
  - 原版：版本 JSON → 客户端 JAR → 库 → 资源索引 → 资源对象
  - Forge / NeoForge：`maven` 元数据 → 安装器（新旧两种方式）→ 支持库
  - Fabric / Quilt：meta API → 主文件 → Fabric API / OptiFabric
  - LiteLoader / OptiFine：独立安装器（方式 A/B 双路径）
  - 服务端下载、版本隔离、增量修补、Mappings 下载

### 6.3 Minecraft 实例与启动

- `McFolder` / `McInstance` / `McInstanceLock` / `McLibEntry`（`ModMinecraft`）
- 版本 JSON 规则求值 `McJsonRuleCheck`、库表展开 `McLibListGet`、资源索引 `McAssetsGetIndex`、缺失文件修补 `McAssetsFixList`
- 启动流水线 `ModLaunch`（16 段，全部是加载器名字）：`登录 → 获取 Java → 补全文件 → 获取启动参数 →
  解压文件 → 预启动处理 → 执行自定义命令 → 启动进程 → 等待游戏窗口出现 → 结束处理 → 内存优化`
- `ModWatcher`：监听游戏日志与进程退出，做「启动成功 / 崩溃」判定
- `ModJava`：注册表 + 目录扫描 + `java -version` 探测，按版本区间为 Forge/NeoForge 选 Java

### 6.4 整合包 `ModModpack`

CurseForge (`manifest.json`) / Modrinth (`modrinth.index.json`) / HMCL / MultiMC / 纯压缩包 五种格式的解析与安装，
以及反向导出（`PageInstanceExport`）。

### 6.5 登录

`PageLoginMs`（Microsoft OAuth 2.0 设备码 + XBL/XSTS → `login_with_xbox`）、
`PageLoginAuth`（authlib-injector 外置登录，LittleSkin 等）、`PageLoginNide`（Nide8 统一登录）、
`PageLoginLegacy`（正版密码/离线）。皮肤与披风经 `MySkin` / `PageLogin*Skin` 处理。

### 6.6 崩溃分析 `CrashAnalyzer`

对 `crash-reports` 与日志做规则匹配（Mod 冲突、内存不足、Java 版本、显卡驱动、Forge 报错等），输出人话结论。

### 6.7 联机 `PageLinkMain`

内置 EasyTier 组网（`ServerConfig.Link` 提供 Peers / 参数 / 下载地址），`ModNet.FindFreePorts` 做端口分配。

### 6.8 媒体

`ModMusic`（NAudio 播放本地音乐）、`MyBitmap`（Imazen.WebP + `SimpleDecoder` 解码 WebP）、
`MyImage`（圆角/缓存/异步加载）。

### 6.9 秘密模块 `ModSecret`（本样本被改动的地方，详见《02-破解分析》）

- 主题引擎：`Color1..8 / ColorGray1..8 / ColorBg0..1 / ColorSemiTransparent` 由 HSL 生成，
  写入 `Application.Current.Resources` 的 `ColorBrush*` / `ColorObject*` 供 XAML 绑定
- 主题表：`0..4` 免费、`42` 特殊、`5..14` 隐藏主题（`8` 秋仪金需赞助等级 ≥23，`11` 极客蓝需解密游戏，
  `12` 彩色循环、`13` 渐变、`14` 用户自定义 HSL）
- 赞助体系：**土豆码**（`CD` 前缀 + Base64 特征串 + `#` + **ECDSA P-256 签名**），
  公钥硬编码 `EcdsaPublicKey`；解码后得到特征列表（如 `Theme5`、`Update`），
  `CurrentRank` 由特征列表推导，`HasUpdatePermission` 要求等级 ≥12 或含 `Update` 特征
- 识别码 `GetIdentify()`：`HKLM\SYSTEM\HardwareConfig\LastConfig` + 首次生成的随机串 → `StableHashCode` → 4 段 16 进制
- 服务器公告：`notice.cfg` / `notice.json` / `ServerConfig.json`（腾讯云 COS + MD5 签名），
  公告支持条件分支（`d10000 <=`、`opencount <=`、`versioncode <=`、`unlockedtheme =`、`setupinteger >=` 等）
  与动作分支（`copy` / `website` / `stop` / `setup` / `update` / `slientupdate`）
- 更新：`UpdateCheckByButton` → `IsLauncherNewest()` → `UpdateStart` → 下载 zip 或 **PA30 二进制补丁**
  → `UpdateRestart` 用 `--update` 参数拉起 `PCL\Plain Craft Launcher 2.exe` 完成替换

## 8. 线程与并发模型

- **UI 线程**：WPF Dispatcher；`ModBase.RunInUi` / `RunInUiWait` 统一调度，`RunInUi()` 判断是否已在 UI 线程
- **后台线程**：`ModBase.RunInThread`（线程池）、`RunInNewThread(action, name, priority)`（命名线程）
- **下载并发**：`NetTaskThreadLimit = ToolDownloadThread + 1`，`ServicePointManager.DefaultConnectionLimit = 10000`
- **加载器隔离**：每个加载器有自己的取消令牌与状态机，`WaitForExit` 支持把子加载器进度同步到父级
- **去抖**：`ThrottleDebounce` 用于设置写入与 UI 刷新

## 11. 架构评价

**优点**
- 分层清晰：`Mod*`（无状态逻辑）/ `Page*`（视图）/ `My*`（控件）/ `Validate*`（规则）职责边界稳定
- 加载器框架统一了「耗时任务 + 进度 + 取消 + UI 呈现」，下载/安装/启动全部复用同一套
- 主题系统基于 HSL 变量注入 WPF 资源字典，一处改动全站生效
- 镜像与重试策略完善，国内网络环境下可用性高
- 单 exe + 少量 DLL，部署极简

**局限**
- VB.NET + .NET Framework 4.8，无法跨平台，且 32 位进程受 4 GB 地址空间限制
- 核心库 `MeloongCore` / `PCLCS` 闭源，外部无法完整重建
- 全局静态状态（`ModMain.FrmMain`、`ModSecret.Color*`、`ModBase.PathTemp`）遍布，难以单元测试
- 大量 `RunInUi` 嵌套，UI 线程仍是主要瓶颈
- 服务端下发公告可执行 `setup`/`stop`/`website` 等动作，属于远程控制面，攻击面较大
